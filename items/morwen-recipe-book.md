# Morwen's Recipe Book

## Description
A recipe book for spells and potions found in [Morwen](npcs/morwen.md)'s hut in the [Stagnant Swamp](locations/stagnant-swamp.md). A collection of colored liquids was found alongside it.

## Obtained
Found in Morwen's hut after defeating her.

## Colored Liquids
The following colored liquids were found adjacent to the book:

| Recipe | Ingredients |
|--------|-------------|
| 1/3 | Green, Clear, Red | Acid |
| 1/3 | Purple, Red, Clear | No effect |
| 1/2 | Purple, Green | Grey ooze (hostile) |
| 1/2 | Red, Clear |
| 1/4 | Clear, Red, Purple, Green |
